title: Errors
description: Error body format and which ingest statuses the SDK retries.
---

All endpoints are under `/api/v1`. Errors are JSON: `{"detail": ...}`. Validation errors list field locations and messages, never the submitted values.

## Retries

For `POST /api/v1/traces`, only `503` (buffer unavailable, with `Retry-After`) is worth retrying, and then the whole batch. The SDK retries a `503` 3 times (after 1, 2 and 4 s); `401`, `413`, `422`, other errors and connection failures drop the batch at once. Every status is listed under [Ingest](/docs/api/ingest/#responses).
