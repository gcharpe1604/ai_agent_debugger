---
title: Tracing
description: The list of runs, with search, filters and peek.
---

One row per run: name, start time, outcome, duration, span count, errors. Use it to find the run you want.

- **Search** by agent name or trace ID. Press <kbd>/</kbd> to jump to the search box.
- **Filters**: status (Completed, Failed, Unknown), execution mode (live, controlled), agent, and time range.
- **Peek**: click a row (or its eye button) to preview the run beside the table without leaving the list.
