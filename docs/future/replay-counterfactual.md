# Replay and Counterfactual Debugging — Future Scope

Replay and counterfactual debugging are intentionally outside the OJT version 1 scope.

Future work may explore:

- replaying recorded executions with controlled inputs;
- replacing selected model, retrieval, or tool outputs;
- comparing original and modified execution paths;
- evaluating how downstream behavior changes after an intervention.

These capabilities will build on the immutable Run/Span trace model and are not
required for the initial Trace Analysis Platform.
